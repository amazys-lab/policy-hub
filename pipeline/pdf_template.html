使用须知与免责声明

一、本清单包含什么

本清单收录 {{ meta.scope }} 范围内、{{ meta.person_scope }} 可以申报的补贴与扶持政策， 共 {{ meta.count }} 条{% if meta.city_index %}，覆盖 {{ meta.city_count }} 座城市、归入 {{ meta.stat3_value }} 个类别{% else %}，归入 {{ meta.chapter_count }} 个类别{% endif %}。企业专项政策不在本清单范围内。

二、怎么用最省事

    {% if meta.city_index %}
  1. 先在目录「按城市查找」里定位你要去的城市（表格给出该城条数与编号区间），翻到该城章。
  2. 该城章内按补贴类别分成小节（就业创业 / 技能培训 / 落户 / 人才住房 / 人才引进 / 个税 / 税费…），逐节看。
    3. {% else %}
  3. 先看目录定位类别（就业创业 / 技能培训 / 落户 / 人才住房 / 人才引进 / 个税 / 税费…）。
    4. {% endif %}
  4. 按「申报条件」逐项自查，符合的先看「补贴金额」判断值不值得办。
  5. 准备「申报材料」，按「办理方式」走线上或线下渠道。
  6. 动手前再点一次「官方来源」链接，确认政策是否仍在有效期、标准是否更新。

三、三条重要提醒

  • 以官方为准。政策会调整，本清单是某个时点的快照，最终以官方最新文件和经办窗口答复为准。
  • 金额多为文件口径。「据实核算」「按基数比例」「分档」类金额需按个人实际情况测算，本清单只给文件表述。
  • 不代理、不承诺。本清单不提供申报代理服务，也不对审批结果作任何承诺；请警惕任何对审批结果作出保证、或自称有特殊办理渠道的第三方。
