# 06 · 抓取经验（WAF / 编码 / 附件 / 正文）

> 一次性脚本在 `_scripts_history/<批次>/`（gitignore，不在交付仓）。
> 通用小工具在 `policy_hub/collector/tools/`（fetch_url / url2text / search_site）。

## 通用姿势

```bash
curl -sL -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ..." <url> -o page.html
```

失败时的**换姿势顺序**（单次失败永不作结论）：

1. 加 `Referer: https://<该请求 host>/` —— **多站 WAF 的钥匙**（某市全站深栏裸 curl 403(548B)，带头即 200）
2. 换省级/部委直达源（很多市站内容在省站有同步镜像）
3. 试 `/zwgk` 类公开目录前缀镜像、HTTP 降级
4. 定点长超时复测（timeout 递增 60/60/90/90，禁用缓存）
5. 判死只有 404/410；403/412/502/000 都是故障

## 文种分类与正文

- 分类器输入是 `head = <title> + text[:N]`：**长导航政务页会把窗口吃满** ⇒ 文号/公文体词在窗外 ⇒ 判「未归类」。修法=先剥导航/页脚/侧栏抽正文，**不许**调大 N 凑数（阈值只会把另一批页面推进盲区）。
- 解读判据是**位置**判据：解读词必须在公文体词**之后且同段**才算；媒体前缀强信号；栏面后缀不翻案。
- 改分类器的验收 = **「目标类计数变、其余类计数不变」** + 回归样本锁死。
- 「判原文页」≠「是原文」：入库前必人工开正文核对文号/金额/期限。

## 附件下载

- TRS 系站点附件不在 DOM `<a href>` 里，在**内联 JS**：`var apps = [{name:"…",url:"…"},…]`，正则直抽：
  `r'\{\s*name\s*:\s*"([^"]*)"\s*,\s*url\s*:\s*"([^"]*)"\s*\}'`
- 下载带同一把 Referer 钥匙；`--max-time 90` + 重试。
- playwright 渲染政务 TRS 站常 60s 超时 ⇒ **静态正则优先于浏览器渲染**。
- 附件入库记 `body_sha`（内容指纹），重复/漂移可检测。
- 扫描版 PDF（文本层 0 字）不抽取正文，改以官方网页/多源交叉核实文号与数字。

## 站内搜索（发现新政策的路径）

- 直接 POST 搜索接口；hidden input 用其真实 name（如 `#search_keywords`），fill + Enter。
- 列表排序链接记得**清掉 keywords 参数**避免串页。
- 全网搜索是最后手段；**同站换栏 ＞ 全网搜**。

## 替代源判定（原文挂了找替代）

**替代四判据**：同文件 · 同层级 · 同文种 · 同年度——**能打开 ≠ 能替代**，必须开正文核对。
改 `guide_url` 必同改 `source_doc`；改完跑 `build_sources` + 闸门。
